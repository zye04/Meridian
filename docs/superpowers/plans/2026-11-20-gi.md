# Global Illumination Implementation Plan

**Status:** in progress (lane gi, branch `gi`, worktree `../meridian-gi`).
Next: Task 1.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** bounce light without ray tracing: terrain-following SH probes
traced against the heightfield and the far-field tree voxels, a ground
radiance cache fed by the rendered albedo, and (hybrid) a half-resolution
visibility-bitmask screen pass.

**Architecture:** new files `engine/include/meridian/gi.h` +
`engine/src/gi.cpp` (CPU math and constants, unit-tested, the reference
the shaders mirror), `engine/src/render/renderer_gi.cpp` (resources,
clipmap placement, the GI passes), `engine/shaders/gi.glsl` (layouts,
clipmap math, `giIrradiance`) and one compute shader per pass. The scene
reaches the GI through `SceneData.gi` (buffer address) and `giMode`. The
only edits to lighting.glsl/mesh.frag are the ambient hook (the raster
lane owns their sun term).

**Tech Stack:** C++20, Vulkan 1.3, GLSL compute, doctest.

**Spec:** `docs/superpowers/specs/2026-11-20-gi-design.md` (read it first).

## Global Constraints

- No ray tracing in any GI pass: no `rayQueryEXT`, no TLAS reads.
- `--gi off|probes|hybrid`, default `off`; with `off` no GI pass runs, no
  GI resource is created, and the image matches main (mean diff < 1e-3/255
  on the open view).
- Constants from the spec: 5 probe levels, spacing `2 m x 2^k`, 48 x 48
  columns, 8 slices at `h_t = b_k (2^t - 1)`, `b_k = 0.25 m x 2^k`; column
  base = max bilinear height over the footprint + 0.05 m; ground cache 4
  levels of 256^2 at 1, 2, 4, 8 m; hysteresis 0.9; 64 rays per probe
  update; level 0 updates 1/4 of its probes per frame, levels 1-4 1/8;
  rays to 4 km; screen pass radius 2 m, thickness 0.5 m, 32 sectors, 2
  slices, 8 steps per side, temporal blend 1/8, fade 60-100 m.
- Lighting is relative to a sun illuminance of 1 (lighting.glsl's units);
  probes store radiance SH in those units.
- Read the far field only through `farFieldTransmittance` (farfield.glsl);
  don't change its format. Sky: `skyLuminance` + `skyCaptureAt` only.
- Every pass gets one `endPass("gi ...")` in renderer_frame.cpp.
- Commits: no AI attribution, no Co-Authored-By; one feature per commit.
  CLAUDE.md (flags, frame order, layout, conventions) and decisions.md
  updated in the same commit as the change. No debug leftovers.
- Game runs: `flock /tmp/meridian-gpu.lock ./build-release/game/game ...`,
  held only for the run; captures fullscreen 2560x1440; iterate in Release
  with `--placement off` where placement doesn't matter; Debug + validation
  before each merge. Temp files in `.superpowers/` of the worktree.

## Review Focus

- **Camera teleport / large jump (new `--camera` far away, or a reset):**
  every probe and ground texel re-initializes (no stale light from the
  old place, no black frame). Task 4 tests it with two captures from
  different starts that converge to the same image.
- **Camera beyond the crop (mirrored terrain) and at 3000 m altitude:**
  the clipmaps still centre on the camera; at altitude the probes sit
  on the terrain far below, receivers far below read them, nothing NaNs.
  Task 4: the high overview and the crop-edge view captured, no NaN/inf
  (`tools/image-gates.py` diff vs off shows finite values).
- **Sun below the horizon / at 2 degrees:** ground radiance goes to the
  sky's share only, no negative SH, no overflow. Task 5: dusk view.
- **No far field (`--trees` off, the default) and `--clouds off`:** the
  tree term and the sky capture are skipped or neutral, not garbage. Task
  4 runs the default (no trees) and Task 7 runs `--trees`.
- **Resolution / AA change (`setAntiAliasing`, TAA render scale):** the
  guides, attachment 7 and the screen-pass targets follow the render size.
  Task 6 runs `--aa taa --render-scale 0.67` once.

### Task 1: GI constants and CPU math

**Files:**
- Create: `engine/include/meridian/gi.h`, `engine/src/gi.cpp`
- Modify: `engine/CMakeLists.txt` (add gi.cpp), `tests/CMakeLists.txt`
- Test: `tests/gi_test.cpp`

**Interfaces:**
- Produces (namespace `meridian`):
  - constants `kGiLevels = 5`, `kGiColumns = 48`, `kGiSlices = 8`,
    `kGiSpacing0 = 2.0f`, `kGiSliceBase0 = 0.25f`, `kGiGroundLevels = 4`,
    `kGiGroundTexels = 256`, `kGiGroundTexel0 = 1.0f`, `kGiRays = 64`,
    `kGiHysteresis = 0.9f`.
  - `float giSpacing(uint32_t level)`, `float giSliceBase(uint32_t level)`.
  - `float giSliceHeight(uint32_t level, float slice)` = `b (2^t - 1)`;
    `float giSliceCoordinate(uint32_t level, float height)` its inverse,
    clamped to [0, kGiSlices - 1] (height < 0 -> 0).
  - `std::array<int32_t, 2> giClipmapOrigin(float spacing, int32_t columns, float x, float z)`:
    the first column index (x, z) of a window of `columns` centred on the
    camera, `floor(x / spacing) - columns / 2` (works for probes and the
    ground cache).
  - `uint32_t giToroidal(int32_t column, int32_t columns)`: wrap into
    [0, columns), correct for negatives.
  - `struct ShL1 { std::array<Vec3, 4> c; }`, `void addRadianceSample(ShL1 &sh, Vec3 direction, Vec3 radiance, float weight)`,
    `Vec3 shIrradiance(const ShL1 &sh, Vec3 normal)`: L1 projection
    (Y00 = 0.282095, Y1m = 0.488603 {y, z, x}) and the Geomerics
    non-negative L1 irradiance reconstruction per channel.

- [ ] **Step 1: Write the failing tests** (`tests/gi_test.cpp`)
  - `giSliceCoordinate(k, giSliceHeight(k, t)) == t` (1e-5) for k 0..4,
    t 0..7; height -1 -> 0; height 1e6 -> 7.
  - `giSliceHeight(0, 7) == 31.75f`, `giSliceHeight(4, 7) == 508.0f`.
  - `giClipmapOrigin(2, 48, 0.9, -0.1) == {-24, -25}`; at x = 1e5 the
    window contains floor(x / spacing).
  - `giToroidal(-1, 48) == 47`, `giToroidal(48, 48) == 0`.
  - Uniform radiance L over 4096 Fibonacci directions (weight 4 pi / n):
    `shIrradiance` == pi L (1e-2 relative) for 6 axis normals.
  - A radiance of 1 over the upper hemisphere only: irradiance up ~= pi
    (5%), down ~= 0 (<= 0.1), and >= 0 for 100 random normals.

### Task 3: GI mode, resources and the sampling hook

**Files:**
- Modify: `engine/include/meridian/renderer.h` (`enum class GiMode { Off, Probes, Hybrid }`,
  `void setGiMode(GiMode)`, `GiMode giMode() const`), `renderer_impl.h`,
  `renderer_setup.cpp` (guides created when `wantsGuides() || giMode != Off`),
  `renderer_frame.cpp`, `gpu_types.h`, `engine/shaders/common.glsl`
  (`SceneData`: `pad6` -> `uint giMode`, then `GiBuffer gi` + pad),
  `engine/shaders/lighting.glsl`, `engine/shaders/mesh.frag`,
  `engine/CMakeLists.txt`, `game/src/main.cpp` (`--gi off|probes|hybrid`),
  `CLAUDE.md`
- Create: `engine/src/render/renderer_gi.cpp`, `engine/shaders/gi.glsl`,
  `engine/shaders/gi_probe_init.comp`

**Interfaces:**
- Produces:
  - GPU struct `GpuGi` (gpu_types.h, "must match `GiBuffer` in gi.glsl"):
    per probe level `ivec2 origin` (first column) + `float spacing, sliceBase`;
    per ground level `ivec2 origin` + `float texel`; bindless ids of, per
    probe level, three SH volumes (R, G, B; 3D 48 x 48 x 8 RGBA16F) and a
    base-height map (2D 48 x 48 R32F), and per ground level the albedo
    (RGBA8) and radiance (RGBA16F) maps (2D 256^2); `uint frame`, `uint
    reset`. One image per level so a dedicated sampler (linear, U/V
    REPEAT for the toroidal wrap, W CLAMP_TO_EDGE, no mips) filters
    across the wrap without mixing levels. Storage access through binding
    arrays in the GI compute set.
  - `renderer_gi.cpp`: `Impl::createGi()`, `Impl::destroyGi()`,
    `Impl::placeGi(Vec3 camera)` (origins per level; returns which
    columns entered via a per-level "dirty" rectangle list in GpuGi or a
    full reset flag on a jump > half a window), `Impl::drawGiProbes(cmd, frame)`.
    Descriptor set 0 of the GI compute layout = the storage views of all
    GI images (GENERAL); set 1 = bindless (as the clouds' layout); push
    constants `GiConstants { uint64 scene; uint level; uint pass; }`.
  - gi.glsl: `GiBuffer`, `vec3 giIrradiance(SceneBuffer scene, vec3 worldPosition, vec3 normal, vec3 fallback)`
    (fallback = today's sky/ground mix, used beyond level 4 with the spec's
    4-column fade), slice/toroidal helpers mirroring gi.h.
  - lighting.glsl: `Shading.worldPosition` (flat), set in `beginShading`;
    `addAmbientLight` uses `giIrradiance(...)` for the diffuse when
    `pc.scene.giMode != 0`, and `giIrradiance(R)` in place of
    `skyIrradiance` in the rough-specular fallback; mesh.frag's leaf back
    irradiance uses `giIrradiance(-N)`.
  - `gi_probe_init.comp`: writes every probe's SH from the analytic
    ambient (sky irradiance above, `kGroundAlbedo` ground below, as an L1
    lobe), so this task's `--gi probes` reproduces `--gi off` closely.
    Run on reset and for entered columns (later tasks keep it as the
    initializer).

### Task 4: Probe tracing

**Files:**
- Create: `engine/shaders/gi_probes.comp`
- Modify: `renderer_gi.cpp`, `renderer_frame.cpp`, `engine/CMakeLists.txt`,
  `engine/shaders/gi.glsl`

**Interfaces:**
- Consumes: `terrainRayDistance` (Task 2), `farFieldTransmittance`,
  `skyLuminance`, `skyCaptureAt`, `giIrradiance` (multi-bounce at hits),
  `GpuGi` (Task 3).
- Produces: `gi_probes.comp`, one 64-thread workgroup per updated probe
  (indirect or direct dispatch over the level's update subset:
  `probeIndex = frameSlot + stride * groupId`), one ray per thread
  (spherical Fibonacci of 64, rotated by a per-frame rotation from
  `frame`); hit radiance per spec ("Rays"); fallback albedo for ground
  hits until Task 5 (`kGiFallbackAlbedo`, linear (0.06, 0.09, 0.03)) lit
  by `sunAtSurface x NoL` (heightfield normal from the normal map) + albedo
  x `giIrradiance` at the hit; shared-memory reduction to SH L1; blend
  `mix(new, old, reset ? 0 : 0.9)`. The column base heights are written for
  entered columns (`terrainHeightBounds` + 0.05 m).

### Task 5: Ground cache and albedo feedback

**Files:**
- Create: `engine/shaders/gi_albedo.comp` (scatter + resolve variants via
  a define), `engine/shaders/gi_ground.comp`
- Modify: `renderer_gi.cpp`, `renderer_frame.cpp`, `gi.glsl`,
  `gi_probes.comp`, `engine/CMakeLists.txt`

**Interfaces:**
- Consumes: depth + diffuse albedo attachments (render size), GpuGi.
- Produces: `gi_albedo.comp` SCATTER (per render pixel: opaque, world
  height <= heightAt + 1.5 m, inside ground level k: atomicAdd of the
  albedo in 10-bit fixed point + count into a per-texel uint4 accumulator
  buffer, for every level holding it) and RESOLVE (per texel: mean ->
  `mix(old, mean, 0.1)`, alpha confidence += 0.1; clears the accumulator);
  `gi_ground.comp` (per texel, 1/4 per frame by a frame slot, all on
  reset: radiance = `albedo / pi x (sunAtSurface x NoL x V + giIrradiance(texel, up))`,
  `V = giGroundSunVisibility(world, N)` = `!terrainOccludes` x
  `farFieldTransmittance` toward the sun (if the far field is enabled) x
  `cloudShadow`); `vec3 giGroundRadiance(GiBuffer, vec2 xz)` in gi.glsl
  (finest level holding xz; unseen albedo -> coarser level -> fallback),
  used by gi_probes.comp's ground hits. Passes: `gi ground` (before
  `gi probes`), `gi albedo` (after the late scene pass).
